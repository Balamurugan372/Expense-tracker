# Expense-tracker
This will help to monitor  daily expense and control easily

📌 1. Project Overview

**Smart Expense Tracker System** 
is a web-based expense management application developed using **HTML, CSS, JavaScript, Java, and SQLite**.
The application allows users to record their daily expenses and manage their expense information through a simple and user-friendly interface.
The frontend communicates with the Java backend through HTTP API requests, while SQLite is used to store the expense records.



 🎯 2. Project Purpose
The main purpose of this project is to provide a simple digital solution for managing daily expenses.
The system helps users to:
- 💰 Record daily expenses- 📋 View expense records- 🔍 Search expenses- 🗑️ Delete expenses- 📊 Calculate total expenses
- 💳 Store payment method details- 📈 Monitor the number of transactions
Techstack:
🎨 Frontend : HTML, CSS, JavaScript 
⚙️ Backend :Java 
 🌐 API  Java HTTP Server 
 🗄️ Database ,SQLite 
 🔌 Database Connectivity, SQLite JDBC
 💻 IDE -Visual Studio Code
